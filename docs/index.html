Which country weights hold up?

Darker cells indicate a larger weight. Countries that retain a meaningful weight across settings rely less on a single choice of lookback or shrinkage.

Method and data

The models use matched Friday-ending USD returns and annualize weekly means and covariance using 52 weeks. Shrinkage pulls each country’s estimated return toward the cross-country average. Portfolios are fully invested and long only. The frontier’s highlighted portfolio maximizes expected return divided by volatility, using a zero risk-free rate.

ETFs use adjusted prices. Local indices are converted from local currency into USD. Results describe the historical sample and depend on model assumptions.
